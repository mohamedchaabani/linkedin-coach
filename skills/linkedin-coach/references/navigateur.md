# Modifier le profil via le navigateur connecté

S'applique uniquement si un outil de navigation est **déjà** connecté au compte LinkedIn de
l'utilisateur (par exemple Claude in Chrome). Sinon : du texte prêt à copier, rien d'autre.
Règle non négociable : **une validation = une modification**.

## Périmètre autorisé

Sur **le propre profil** de l'utilisateur uniquement : titre, section Infos, description
d'une expérience, compétences (ajout, suppression, épinglage), Sélection, URL personnalisée.

## Interdit en toutes circonstances

Publier ou programmer un post ; commenter ; réagir ; envoyer un message ou une invitation ;
modifier les paramètres du compte ; lire ou parcourir d'autres profils ou le fil ; saisir un
mot de passe ; activer l'annonce au réseau sans accord explicite séparé.

Demande de publication, de message ou d'invitation → refuser en une phrase et donner le
texte prêt à copier.

## Séquence pour chaque modification

1. **Montrer** : la section visée, le texte actuel (relu sur la page), le texte proposé, en
   clair.
2. **Demander** une validation qui nomme cette seule modification :
   - FR : « J'applique ce nouveau titre sur ton profil ? (oui / non) »
   - EN : "Shall I apply this new headline to your profile? (yes / no)"
3. **Attendre** un « oui » explicite à cette question précise. Tout le reste n'est **pas**
   une validation : silence, « ok », « ok pour tout », réponse ambiguë, nouvelle demande.
   « Applique tout » → reprendre la séquence pour chaque modification, une par une.
4. **Appliquer** uniquement le texte validé, sans retouche.
5. Si une option « annoncer au réseau » / « Share with network » apparaît : la laisser ou la
   mettre sur **désactivée**, sauf accord explicite séparé.
6. **Vérifier** : relire la section sur la page et comparer au texte validé ; dire
   « conforme » ou montrer l'écart.
7. **En cas d'échec** (page changée, session expirée, champ introuvable, écart) : s'arrêter,
   dire ce qui a été appliqué ou non, fournir le texte à copier. Ne pas réessayer sans
   nouvelle validation.

## Lecture seule (import)

Pour lire son propre profil avant un audit : naviguer uniquement sur l'URL de son profil,
lire, ne rien cliquer qui modifie. Voir `references/sources-profil.md`.
