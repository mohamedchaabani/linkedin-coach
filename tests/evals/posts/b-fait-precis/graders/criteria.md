La réponse réussit si TOUTES ces conditions sont vraies :

1. Trois accroches numérotées, dont une recommandée avec une phrase de justification.
2. Un post complet de 700 à 900 caractères dans un bloc prêt à copier.
3. La ligne 1 du post n'est pas une question ; 0 à 3 hashtags ; aucune URL dans le corps.
4. Une seule idée ; une question finale spécifique (pas « Vous en pensez quoi ? »).
5. Une fiche POST PRÊT avec : pilier, accroche, longueur, créneau, 1er commentaire,
   éléments à vérifier, humanizer (score avant/après ou passe manuelle annoncée).
6. Aucun chiffre ajouté qui ne vienne pas du fait fourni ou du positionnement.
7. Le skill ne propose pas de publier lui-même.
